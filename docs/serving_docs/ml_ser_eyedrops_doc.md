## ML-витрина: ml_ser_eyedrops

Универсальная витрина данных для машинного обучения на основе проницаемости роговицы для малых молекул.
Может использоваться для различных задач регрессии и классификации, где любой столбец может быть целевой переменной.

### Ключевые признаки:

- **Структурные**: SMILES-представление молекулы
- **Физико-химические**: проницаемость роговицы (perm_cleaned), липофильность (logp_cleaned)
- **Категориальные**: категория липофильности (logp_category)
- **Временные**: год публикации, десятилетие

### Статистика заполнения:

- `perm_cleaned`: ~72% заполнено (28% пропусков)
- `logp_cleaned`: ~33% заполнено (67% пропусков)
- Остальные основные поля: 100% заполнены

### Примечания по использованию:

- Для задач предсказания проницаемости рекомендуется использовать молекулярные дескрипторы, вычисленные на основе SMILES
- Для обработки пропущенных значений в logp_cleaned можно использовать вычисленные значения logP из RDKit или других химических библиотек
- Категория logp_category может использоваться для задач классификации

### Типичные задачи ML:

1. Предсказание проницаемости роговицы (perm_cleaned) на основе SMILES и logP
2. Анализ зависимости проницаемости от липофильности
3. Классификация молекул по категориям проницаемости
