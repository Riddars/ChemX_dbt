## ML-витрина: ml_ser_complexes

Универсальная витрина признаков для металл-хелатных комплексов.  
Используется для задач регрессии (например, предсказание константы стабильности `target_cleaned`).

### Включены признаки:

- `target_cleaned`: числовое значение свойства, пригодное в качестве `target`
- `smiles`, `metal`, `compound_id` и пр. — химическая структура и контекст
- Публикационные метаданные: `access`, `publisher`, `year`, `supplementary_bool`

---

## Исключённые столбцы и причины

| Столбец              | Причина исключения                       |
|----------------------|------------------------------------------|
| target_original      | Строка-источник, не пригодна для ML напрямую |
| target_numeric       | Дубликат `target_cleaned`                |
| origin_target_value  | PDF-навигация                            |
| page_target_value    | Номер страницы — вспомогательное         |
| origin_smiles        | Источник SMILES — дублируется             |
| page_smiles          | PDF — неявный шум                         |
| origin_metal         | Контекст — не влияет явно                |
| page_metal           | Навигация                                |
| pdf, title           | Текстовая инфа из публикации             |
| dbt_curated_at       | Техническое поле                         |
