## ML-витрина: ml_ser_co_crystals

Универсальная витрина признаков по многокомпонентным кристаллам (co-crystals).  
Годна для разных задач предсказания, включая:

- предсказание фотостабильности (`photostability_change`)
- моделирование взаимодействий API + коформер

### Содержимое витрины:

- SMILES-структуры: `smiles_drug`, `smiles_coformer`
- Соотношение компонентов: `ratio_component_1`, `ratio_component_2`
- Глобальные признаки: `year`, `journal`, `access`
- Цель (по умолчанию): `photostability_change`
- Метки: `doi`, `source_table`

### Исключено:

- Позиции из PDF-а (page, origin, section)
- Вспомогательные признаки (`*_type_file`, `pdf`, `authors`)
- Дублирующая информация (`name_*`)

Витрина пригодна для feature selection, обучения моделей, AutoML.


## Исключённые столбцы и причины

| Столбец                   | Причина исключения                                                       |
|---------------------------|--------------------------------------------------------------------------|
| ratio_cocrystal_origin    | Используется только как указание на источник (таблица, рисунок), не информативен |
| ratio_cocrystal_page      | Номер страницы PDF — не нужен                                            |
| ratio_cocrystal_page.1    | Повторяет предыдущий — навигационный                                     |
| smiles_drug_origin        | Источник SMILES — уже учтен значением в `smiles_drug`                   |
| smiles_drug_page          | PDF-номер — не даёт дополнительной информации                            |
| smiles_coformer_origin    | То же самое — вкладка навигации                                          |
| name_drug / name_coformer | Названия в тексте — заменены на структурные SMILES                      |
| page                      | Общий номер страницы статьи — пропущено                                   |
| photostability_change_origin / page / type_file | Просто координаты — уменьшает репрезентативность, не используется |
| title / authors / pdf     | Метатекст — не даёт информативности для модели                           |
| section_* / origin_*      | Все поля из PDF-навигации — не являются фичами                            |
| supplementary             | Может быть включено позже в расширенной версии, сейчас — не используется |
