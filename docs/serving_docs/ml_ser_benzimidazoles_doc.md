## Цель витрины

Создать очищенный набор признаков для обучения моделей на данных по бензимидазолам.  
Используется в задачах регрессии или классификации активности соединений в зависимости от структуры и других признаков.

---

## Что включает витрина

Оставлены только те признаки, которые:
- непосредственно участвуют в формировании предсказаний (целевые переменные, бактерии, SMILES)
- имеют высокую заполненность
- несут воспринимаемую информативность

**Включённые поля:**

| Поле                 | Назначение                                                       |
|----------------------|------------------------------------------------------------------|
| `compound_id`        | Идентификатор соединения                                         |
| `smiles`             | Химическая структура соединения в формате SMILES                |
| `target_value_parsed` | Цель для обучения моделей (числовое значение активности)        |
| `target_value_error` | Погрешность измерения (осталась для анализа доверия)            |
| `target_relation`    | Контекст оператора (`<`, `=`, `>`), может быть категориальным фичем |
| `target_type`        | Тип таргета (MIC или pMIC)                                       |
| `target_units`       | Единицы измерения активности                                     |
| `bacteria_unified`   | Унифицированная структура бактерии                               |
| `year`               | Год публикации (индикатор времени)                               |
| `access`             | Флаг Open Access (может быть категориальной переменной)          |
| `doi`, `source_table`, `dbt_loaded_at` | Вспомогательные поля, полезны для аудита данных |

---

## Что было исключено и почему

**Удалены поля:**
- `section_*`, `subsection_*`, `origin_*`, `page_*` — мета и навигационные поля для PDF-документов, не пригодны для ML
- `bacteria` — заменено более чистым полем `bacteria_unified`
- `target_value` — оставлена числовая версия
- `title`, `pdf`, `publisher` — описательные поля, не влияющие на результат

---

## Применение

Эта витрина может использоваться:
- для регрессии (предсказание MIC)
- для классификации (если создать бинары: например, MIC ≤ 10 → `1`, иначе — `0`)
- как основа для создания feature store
